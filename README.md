MR1T Cell Developmental Single-Cell Analysis Pipeline
Overview

This repository contains the analysis scripts used to process and analyze single-cell RNA-sequencing (scRNA-seq) and paired TCR-sequencing (scTCR-seq) data from neonatal cord blood (CB) and adult MR1-5-OP-RU tetramer–positive MR1T cells.

The code reproduces the transcriptomic, clonotypic, diversity, and downstream analyses presented in the associated manuscript. This repository contains analysis workflows and scripts; it is not packaged as standalone software.

Data Availability

All raw sequencing data have been deposited in dbGaP under controlled access:

dbGaP accession: phs003810.v1.p1

Because these datasets derive from human participants and are subject to controlled-access policies, raw sequencing data are not redistributed via GitHub. Investigators wishing to reproduce the full analysis should apply for data access through dbGaP and, once approved, download the data and place them into the directory structure described below.

Processed data objects necessary to reproduce figures are generated by the scripts in this repository after access to the raw data is obtained.
